# Covro 使用指南

[English overview](../README.md) · [中文介绍](../README.zh-CN.md)

源码和开发命令在仓库根目录执行；全局安装后，可在任意目录使用 `covro` 命令。

私人电脑上的 Codex 网页客户端。默认中文，单用户、单网关、单受管 `codex app-server`；支持本机、Tailscale Serve 或 Cloudflare Access 访问，页面、API 和 WebSocket 共用配置的访问入口。

项目规范：[codex-web-ui-mvp.md](../codex-web-ui-mvp.md)。实现分层、验收结果与边界见 [architecture](architecture.md)、[verification](verification.md)、[compatibility](compatibility.md)。

## npm 安装与后台运行

Covro 面向已有 Node.js 和 Codex 环境的用户，npm 包包含构建好的页面、服务和数据库迁移。

```sh
npm install -g @covro/covro
covro
covro status
covro update
covro update --channel dev
```

默认后台常驻，`covro run` 可在前台调试；`covro service install` 单独启用登录自启。默认配置和数据保存在 `~/.covro/`，也可通过 `--config` 沿用现有配置。

macOS 有桌面会话时使用 GUI launchd 后台运行，以保留系统钥匙串访问条件；不自动开启登录自启。`covro doctor` 从运行实例检查会话与 GitHub 凭证，不输出令牌，检查范围不包括 Codex 的 Agent/Shell 沙箱。安装会话修复后请停止并重新启动旧实例。详见[会话与凭证诊断](distribution.md#macos-sessions-and-credentials)。

网页侧栏的「Covro 更新」可检查版本、选择稳定/预览/开发渠道、开启空闲时自动升级，以及一键升级并重启。配置、项目和历史跨版本沿用，新版验证失败会恢复上一可用安装；降级仍需通过数据库兼容检查。发布与平台支持边界见 [分发和升级说明](distribution.md)。

## 源码开发与本机运行

要求 Node.js **24.19.0**（LTS）、pnpm **12.11.2**、已安装并登录的 Codex CLI。协议生成与已验证运行目标为 **0.163.0**。依赖版本固定于 `package.json` 和 `pnpm-lock.yaml`。升级与回退说明见 [Codex 0.163.0 兼容性记录](codex-0.163.0-verification.md)。

```sh
pnpm install --frozen-lockfile
cp config.example.json config.local.json
# 启动后在页面添加服务器上的项目目录，也可继续使用 JSON projects 配置。
pnpm dev
```

开发页面为 <http://127.0.0.1:5173>，Vite 将 `/api` 和 `/ws` 代理至后端 8787。开发 origin 必须显式写入 `developmentOrigins`，只有 `--dev` 时启用。两端均仅监听回环地址。

生产构建与运行：

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm start -- --config ./config.local.json
```

生产页面可通过 `publicOrigin` 数组中的任一地址访问（示例配置同时允许 <http://127.0.0.1:8787> 和 <http://localhost:8787>）。可从任意目录以绝对路径启动：

```sh
node /absolute/path/codex-web-ui/dist/server/main.js --config /absolute/path/codex-web-ui/config.local.json
```

不要用开发服务器作为 Tunnel 的源服务。`dist/` 中包括浏览器产物、服务端模块和迁移；运行时还需要 `package.json` 及已安装的生产依赖。

## 配置与使用

侧栏「服务配置」提供网络与访问、Codex 和高级限制的可视化编辑。页面展示启动时指定的配置文件、当前运行值和已保存值；修改先校验并预览，确认保存后写回原文件，需手动重启服务生效，不会自动中断任务。配置被其他页面或程序修改时会拒绝覆盖，重新读取后可继续编辑。软链接配置或不可写文件只支持查看和导出。

在**服务配置 → 高级设置**中，以 MiB 编辑大小限制（1 MiB = 1024 × 1024 字节）。小数必须精确对应整数字节；已有字节值会原样保留。JSON 文件和 API 继续使用字节，保存后需重启服务生效。

支持导入、导出 JSON 配置。导入先校验并预览，应用到表单后仍需确认保存；保留本机 `dataDir` 和 `projects`，避免导入导致数据目录切换或覆盖项目初始配置。导出的是文件中的已保存配置（包含默认值和项目初始配置），不包含未保存编辑、数据库中的项目注册、会话、数据库或登录凭据。数据目录仅展示，迁移请停服后处理；项目继续通过侧栏管理。

- `projects` 可省略或设为 `[]`，无需预注册目录即可启动。页面的“添加项目”接收运行网关的电脑上的绝对目录；手机或其他电脑访问时也不是选择浏览器本机目录。“已有目录”要求目录已存在并可读取、进入，符号链接按 realpath 归一化；“克隆 Git 仓库”支持 HTTPS/SSH 地址、目标目录和可选名称，复用主机上的 Git 认证，显示进度并支持取消，完成后自动注册。克隆目标须不存在或为空，父目录须已存在且可写，详见[克隆要求与失败恢复](project-clone.md)。任务接口仍只能提交项目 ID，不能覆盖 cwd。
- `codex.binary` 支持绝对路径。后台服务的 PATH 与终端不同，建议填绝对路径。可选 `codex.home` 只设置子进程的 CODEX_HOME；默认继承现有环境。应用不读取或返回登录令牌，不改全局 Codex 配置。
- `dataDir` 相对于配置文件所在目录解析。数据库在 `dataDir/app.sqlite`，目录权限 0700、数据库权限 0600。实例锁覆盖运行服务和显式迁移命令，异常退出后的锁约十秒可恢复。
- `publicOrigin` 是允许访问地址的非空数组，每项填写完整的 `协议://主机[:端口]`，不带路径、通配符、凭据、查询或片段。HTTP 与 WebSocket 都按此列表检查 Host / Origin；`localhost` 和 `127.0.0.1` 需要分别配置。旧配置的字符串需改为数组，例如 `"publicOrigin": ["http://127.0.0.1:8787"]`，修改后重启服务。
- `host` / `port` 控制实际监听地址；`local` 模式要求 `host` 为回环地址，可显式允许 Tailscale Serve 的 HTTPS 入口，由 Tailscale 控制访问身份。公开互联网入口使用 `cloudflare-access` 模式，所有 `publicOrigin` 项必须为 HTTPS，并通过同一 Access 应用的 JWT 校验。具体配置参见 [部署指南](deployment.md)。
- 输入框底部提供图片附件、项目与审批入口，以及合并的模型设置和发送按钮；桌面与窄屏均保持单行。模型按钮显示模型名和推理强度，Fast 开启时显示闪电。点开后可统一调整模型、推理强度及 Fast，关闭按钮、Esc 或点击外部收起弹层。窄屏按可用空间省略模型名，最窄时隐藏重复的项目标识。配置来自 app-server，修改在新建会话或下次任务时生效；缺失值显示“未报告”。详见 [运行配置来源、生效时机与 UI 调研](runtime-settings.md)。

本机升级 Codex 后，若运行版本尚未验证，页面会先提示可能无法正常使用，并要求明确“确认继续”。确认前不能新建、Fork、恢复或发送任务，但仍可查看诊断和中断已有任务。确认在同一服务与 Codex 实例内共享，刷新不会重复询问；重启或版本变化后需要重新确认。初始化失败或已知不支持的操作不能通过确认绕过，详见 [兼容性说明](compatibility.md)。

左侧同时列出所有配置项目及各自的会话，可直接在对应项目下新建或打开会话。正在执行、等待审批和已完成的会话状态会实时更新；查看一个项目时，也能看到其他项目的进展。每个项目独立分页、重试加载，并支持搜索项目与已加载会话；手机上通过“打开项目与会话”展开导航。可在导航中添加项目，或通过各项目的管理入口重命名、移除；变更立即同步到已打开的页面，无需重启。

点击「调整项目顺序」，在电脑上拖拽项目，或在电脑和手机上用上下按钮排序；刷新和重启后顺序仍然保留，新增或重新添加的项目排在末尾。

会话列表以单行标题显示，状态图标位于右侧按钮组最左端：未读的完成结果显示主题色圆点，执行中为旋转图标，等待审批为带提示点的盾牌，等待回答为对话气泡；失败、中断和待核对也有独立图标。打开会话并在前台看到最新完成结果后，圆点消失；已经读过的完成会话和空闲会话不显示状态图标。下一轮完成后会再次提示未读，重命名和刷新不会重置已读状态。后台标签页、只展开会话详情或仍在查看旧消息时不会标记已读。阅读记录保存在当前浏览器，同源标签页同步；不跨设备同步，存储不可用时仅保留当前页面记录。没有末轮记录的历史会话不会推断为未读完成。

侧栏底部的「设置」→「浏览器通知」可开启浏览器系统通知、查看授权状态并发送测试通知。通知区分完成、失败、中断、需要回答和需要审批，显示项目与会话；点击待处理通知会打开对应会话并定位提问或审批卡片，请求已结束时打开会话。结构化提问、异步提问、命令、文件、网络、权限及 MCP 请求共用通知开关；同源标签页通过 IndexedDB 按轮次或请求去重。通知只由在线期间新出现的实时事件触发，刷新、重连和历史加载不会重放旧通知；发送前核对请求仍待处理，去重存储不可用时暂停系统通知，页内交互仍可用。前台和后台均遵循相同策略。需要支持通知的桌面浏览器，以及 HTTPS 或本机 localhost/127.0.0.1。请保持页面与浏览器运行；本功能不使用 Web Push，页面被冻结或回收期间不能保证即时通知，恢复后会同步结果。设置面板提供 Chrome/Edge 的保持网站活跃指引，需用户手动配置。

悬停图标可查看状态和待处理数量；离线时停止旋转并提示“上次已知”。右侧“会话详情”按钮可通过点击、触屏或键盘展开完整标题、创建来源、更新时间、任务状态、阅读状态和待处理数量；Escape 收起详情。创建来源优先使用 Codex 记录的创建客户端：本网页显示 Web，终端显示 CLI，已识别的编辑器和桌面应用分别显示 VS Code、Codex Desktop。缺少创建方记录时，`vscode` 仅显示“交互客户端”，`appServer` 显示 MCP；来源不表示当前运行位置或连接状态。

在侧栏展开“会话详情”，或打开顶部“状态诊断”的“当前会话”，可查看服务端返回的完整 **Thread ID**，用于定位会话或在其他工具中引用。ID 可选中复制，也可点击复制按钮；成功后短暂显示“已复制”，剪贴板不可用时提示手动选择复制。窄屏自动换行。状态诊断随当前选择更新；尚未发送首条消息时显示“会话尚未创建”，详情未加载或加载失败时显示对应状态，不保留上一会话的 ID。Fork 显示副本自己的 ID。

项目管理规则：

- 注册信息保存在 `dataDir/app.sqlite`，重启后保留。JSON 中首次出现的项目 ID 会作为初始注册导入；已有 ID 的页面名称和移除状态以数据库为准。删除 JSON 条目不会删除已导入的注册，修改已有 ID 对应的目录会报身份冲突。
- 项目目录绑定不可修改，重命名只修改显示名称。同一真实目录不能通过页面重复注册，即使使用不同的符号链接；已有 JSON 中的重复目录 ID 保持兼容；同目录有多个旧 ID 时，再次添加会优先恢复最早注册的已移除 ID，不创建新 ID。
- 移除仅隐藏项目，不删除实际文件、Codex 历史或会话关联。再次添加同一真实目录会恢复原 ID 和历史；已关联的历史不会因添加父目录、子目录而改归另一个项目。
- 有活动任务、待核对执行或尚未结束的创建/恢复/Fork 操作时不能移除。先等待任务结束、正常中断或完成已有的提交核对流程。目录暂时不可用的项目仍可移除。
- 注册时记录真实目录，原路径的符号链接若后来指向其他位置，项目会显示不可用，不会自动将历史和权限转移到新目录。

会话草稿、未选会话时的项目草稿，以及各项目的模型/执行设置在当前页面内分别保留；切换项目不会混用。历史包括 Codex 的 `cli`、`appServer`、`vscode` 分类。打开未受当前服务管理的历史会话时，页面会自动尝试恢复，由 Codex 的跨进程写入锁判断占用。只有明确被其他进程占用时才显示提示，提供 Fork 和重试恢复；释放占用后重试即可继续原会话。本应用不会接管或结束其他终端进程。

新建会话快捷键为 macOS 的 **⌘ + Option + N**，Windows/Linux 的 **Ctrl + Alt + N**，当前工作区的“新建会话”按钮提示中也会显示。增加 Option/Alt 是为了避开浏览器保留的 ⌘N/Ctrl+N 新建窗口操作。快捷键与按钮共用流程：保留当前项目（或“未关联项目”范围），打开该工作区的已有草稿并聚焦消息输入框，发送首条消息后才真正创建会话。原会话的文字、图片草稿与模型设置继续保留。输入法组合输入和候选确认期间、弹窗或下拉菜单打开时不响应快捷键，按住按键也不会重复触发；连接、兼容性确认、创建中或设置保存等限制与按钮一致。

打开已有会话后点击“Fork 会话”，会复制 Codex 已保存的历史并切换到新会话，可以在副本上继续对话。空会话需先发送首条消息。“此会话正被其他进程使用”及“提交结果尚未确认”提示也提供 Fork 入口，无需先停止原会话；原会话保持不变。Fork 不复制未发送的草稿或待处理审批，也不会创建新的项目目录。新会话可与原会话在同一目录并行执行，原会话等待审批或状态待核对也不会阻塞它。Fork 回执丢失时先查询同一操作 ID，避免创建重复副本。

不同会话可以在同一目录或 checkout 同时执行任务。需要隔离文件改动时可自行使用 Git worktree；应用不会自动创建 worktree。执行中输入框变为追加要求；中断需要等待真实终态。工具命令、输出、文件变更和 diff 按所属 turn 展示。点击「本轮变更预览」或工具活动中的文件路径，打开只读代码变更窗口；宽屏在会话右侧展示，窄屏全屏阅读，关闭后恢复原来的阅读位置和焦点。同一快照中的所有文件纵向排列，可以连续滚动阅读；每个文件显示路径、新增/删除/修改/重命名类型、增删行数，并可独立展开或收起。滚动阅读时，当前文件的标题栏吸顶，路径、统计和收起按钮保持可见，滚动到下一个文件时由其标题栏接替；区块跳转会为吸顶标题留出空间。超过 300 行或 50,000 字符（收到的代码行及区块头，按 UTF-16 计数）的文件默认折叠，提示原因，展开后才计算行内高亮并渲染代码行；折叠不代表补丁被截断。通过工具文件入口打开时会定位并展开该文件。支持新旧行号；相近增删行中变化的词会以更深的底色突出显示，支持跳转变更区块，长行支持横向滚动或自动换行。打开时通过会话历史接口重新读取对应轮次或工具的补丁，展示 Codex 保存的该范围快照，不等于工作区全部未提交变更。空补丁、读取失败、截断或不支持的格式以及二进制文件均有提示；读取失败可重试。审批及结构化问题在人工请求区域处理；断线不会自动作答。

每轮成功结束后，内容末尾显示总耗时和完成时间。耗时使用 Codex 提供的整轮 `durationMs`，完成时间使用 `completedAt`，按浏览器本地时区显示完整日期、时分秒和 UTC 偏移；刷新、重连及切换会话不会重新计时。历史缺少耗时或完成时间时分别显示“耗时未知”或“完成时间未知”，失败和中断不会显示成功完成提示。

完成信息同时显示本轮平均 TPS（tokens/s）：本轮累计输出 token 增量 ÷ 整轮耗时（秒）。输出包含推理 token，耗时包含工具执行、审批和网络等待；这是整轮吞吐量，不是纯模型生成速度。悬停或聚焦 TPS 可查看统计口径。通过 `thread/tokenUsage/updated` 采集的结果会保存在网关数据库，刷新、重连和服务重启后仍可查看。旧历史、中途接入、上下文压缩或计数重置导致统计不完整，以及没有有效耗时的轮次显示“TPS 未知”，不会用字符数或会话总量估算。

会话收到用户消息且尚未命名时，会异步生成简短标题，侧栏和顶部同步更新，刷新后仍保留。命名策略对齐 Codex CLI 0.163.0：OpenAI 服务商、ChatGPT 登录且模型列表包含 `gpt-5.6-luna` 时，使用该模型及低推理强度；否则沿用当前会话模型与服务商。标题最多 36 个字符，保持用户语言，会额外进行一次模型推理。生成失败或超时保留首条消息预览，不影响任务；下次收到用户消息时再尝试，不后台循环重试。恢复后的历史会话及 Fork 也适用，但只有未命名且收到新消息才触发；已有名称和生成期间手动设置的名称始终保留。

同一会话只启动一个活动 turn，执行中仍可通过追加要求指导当前任务。发送下一轮或刷新会话详情时，会核实上一轮的已知执行标记：仅在上游历史明确显示对应任务完成、失败或中断且没有其他活动任务时自动释放。无法核实的执行只保留本会话的待核对状态，不影响同目录的其他会话。

额外权限请求会列出网络访问和文件读取、写入范围，可选择仅允许本轮、本会话允许或拒绝。MCP 工具需要补充信息时会显示表单；需要到外部页面完成操作时会显示目标链接，由用户主动打开并确认。刷新或断线不会自动同意、拒绝或取消请求。不支持的表单会明确提示，并保留拒绝和取消入口。

同一轮内连续的工具调用、思考过程与自动审核默认合并收起；用户消息、Codex 回复及不同轮次会切断分组。组标题显示活动数量、执行进度及失败、拒绝、审核超时或结果未确认等状态，展开后可以逐项查看。自动审核卡片默认收起，展开后显示被审核的操作、审核原因和技术详情。长内容的组标题与当前活动标题会分别吸顶，均可直接收起；收起后保留阅读位置，流式更新也不会重置手动展开状态。

在命令输出区域右上角点击复制按钮，可复制全部已加载的输出；截断内容会明确提示。

浏览器刷新或重连可以恢复当前网关已收到的审核记录；这些通知不属于 Codex 保存的会话历史，网关重启后无法重建此前的审核记录。刷新页面后，活动组和审核卡片恢复默认收起。

桌面输入框按 Enter 发送消息，Shift + Enter 换行；执行中按 Enter 会追加要求。手机和平板按 Enter 换行，使用发送按钮发送或追加要求；连续换行和粘贴多行文本保留草稿，首条消息发送前不会创建会话。输入法组合输入及候选确认不会发送。

对话中「需要你的回答」卡片的自由回答框支持多行输入：Enter 或 Shift + Enter 换行，macOS 按 ⌘ + Enter、Windows / Linux 按 Ctrl + Enter 发送当前卡片的回答。按钮显示当前系统的快捷键；全部问题填写完整且允许发送时才会提交，发送中和输入法候选确认不会重复提交。手机和平板仍使用「发送回答」按钮。其他提问卡片和主消息草稿不受影响。

发送规则根据手机/平板平台信息判定（包括 Android、iPhone/iPad/iPod，以及以 MacIntel 平台配合多点触控标识自己的 iPad），不根据窗口宽度、横竖屏或单独的触控能力切换。桌面窄窗口和 Windows 触屏电脑保留桌面快捷键。浏览器不能可靠判断每次 Enter 是否来自软键盘，因此手机/平板外接键盘也采用按钮发送。伪装桌面平台的其他设备可能无法识别。移动端输入框明确提示按钮发送，键盘展开时根据 VisualViewport 调整工作区可见高度；缩放时交由浏览器处理。

拖动输入框右上角的圆弧手柄可以调整高度：向上增高、向下缩小，底部位置保持稳定，也支持触控。用 Tab 聚焦手柄后，↑ / ↓ 每次调整 10 像素，按住 Shift 调整 40 像素，Home / End 分别到达最小 / 最大高度。高度上限会随视口、附件和 Shell 面板的可用空间收紧；长文本在输入框内滚动。

输入框开头输入 `/` 可打开命令菜单，支持 `/help`、`/new`、`/fork`、`/resume`、`/rename <名称>`、`/stop` 和 `/status`。可按名称或说明筛选，使用 ↑ / ↓ 和 Enter 选择执行，Esc 关闭；`/rename` 必须提供名称，其他命令无需参数；未知命令和执行失败会保留输入。`/rename` 持久化当前会话名称；`/resume` 仅恢复当前选中的历史会话，`/stop` 请求中断当前任务；这些命令使用网页已有流程，不透传全部 CLI 命令。输入 `//` 可发送以 `/` 开头的普通消息。详见 [Slash 命令说明与边界](slash-commands.md)。

点击输入框左下角的 **＋** 打开系统文件选择器，手机可从相册或文件中选择图片；也可继续用 Cmd/Ctrl + V 粘贴图片。选择或粘贴不会自动发送，发送前可以预览和移除，也可以只发图片或在执行中追加图片。支持 PNG、JPEG、WebP 和 GIF，每条消息最多 4 张，图片合计不超过 2 MiB；超出限制时先缩小图片。图片草稿随会话在当前页面内保留，刷新页面会丢失未发送的草稿；取消文件选择不会改变草稿；读取失败时保留附件，可点击「重试读取」或移除后重新选择，发送失败或结果未确认时保留草稿。图片通过 Codex 原生图片输入发送，历史预览受显示与连接缓冲限制，未提供预览的图片会显示数量提示。

回复中的本地 Markdown 图片会显示缩略图，点击缩略图或图片文件链接可打开预览。预览支持放大、缩小、适应窗口；可用 Enter 打开、`+` / `-` 缩放、`0` 适应窗口及 Esc 关闭。窄屏内可滚动查看放大的图片。支持普通文件路径与本机 `file://` 链接；加载失败会显示原因和原始路径，并可重试。刷新、重连后，只要文件仍存在且允许访问即可继续预览。

回复中的外部 HTTPS Markdown 图片（包括 GitHub 附件）也会显示缩略图并支持点击放大、重试和打开原图。图片由浏览器直接请求，不经过网关代理，也不要求位于本地项目或临时目录；无文件扩展名、查询参数和跨域 HTTPS 重定向均受支持。远程图片请求不发送 Referer。页面 CSP 的 `img-src` 允许任意 HTTPS 图片来源及其 HTTPS 跳转目标，保留同源、`data:`、`blob:`；外部 HTTP 图片不在允许范围。脚本、连接、frame、base 等其他 CSP 限制不变。上游拒绝访问、图片失效或网络失败时，消息会显示错误、原始 URL 和原图链接；带外层链接的图片保留原有链接行为。

本地输出图片由经过现有登录校验的 `GET /api/threads/:threadId/images?path=...` 读取，文件位于运行 Codex 的电脑上。接口接受绝对路径或相对于会话工作目录的路径（包含空格、中文），开放该会话所属已注册项目目录，以及服务器临时目录中的 PNG、JPEG、WebP 和 GIF 普通文件。临时目录在网关启动时从运行环境的 `os.tmpdir()`（包括 `TMPDIR` 等系统临时目录设置）和 POSIX 系统的 `/tmp` 确定，兼容 macOS 的 `/tmp` → `/private/tmp` 别名；浏览器不能指定临时目录，文件系统根目录不会作为临时目录开放。单张上限为 20 MiB；检查扩展名与文件签名，拒绝超出上述目录范围的路径及符号链接。成功响应使用 `private, no-cache` 和内容 ETag，未变化时返回 304；错误响应禁止缓存。允许范围内可访问的图片应视为对当前登录用户开放。网关已保存会话归属后，Codex 暂时离线或会话已归档不影响图片读取，文件删除、权限变化或项目移除则会明确报错。读取前后会检查文件替换，但不将可被恶意进程并发修改的目录视为安全隔离边界。

同一个图片预览区域内，缩略图和弹窗按会话、原始路径共享已加载的 Blob 与进行中的请求。加载成功后 30 秒内直接复用，不发起接口请求；过期后再次打开时先显示已有图片，同时后台校验，成功后同步更新缩略图和弹窗，失败则清除旧图并显示错误、允许重试。同路径换图或权限变化可能在这 30 秒内尚未反映；仅停留在已打开的图片上不会定时刷新。切换会话、卸载预览区域或刷新页面会清空内存缓存，再次加载仍经过接口校验。缓存不持久化，未使用的图片按最近使用顺序回收，最多保留 32 张、64 MiB；正在显示的图片保持可用，关闭后再参与回收。外部 HTTPS 图片仍由浏览器直接加载。

会话中的本地 `.md` / `.markdown` 文件链接可直接打开只读预览，支持相对路径、绝对路径和本机 `file://` 链接。宽屏（1280px 起）在会话右侧分屏阅读，可同时继续输入；较窄屏幕使用全屏阅读页，顶部固定返回和复制按钮，正文独立滚动，关闭后保留会话位置。可切换渲染预览与原文，一键复制完整 Markdown；剪贴板不可用时会提示手动复制并展示原文。文档中的相对 Markdown 和图片链接按该文件所在目录解析。

Markdown 文件通过 `GET /api/threads/:threadId/markdown?path=...` 读取，复用本地图片的登录校验、会话项目/服务器临时目录范围及符号链接检查，响应仍禁止缓存。仅接受不超过 2 MiB 的 UTF-8 普通文本文件；HTML 不执行。文件缺失、访问受限、类型或编码不支持时显示原因并允许重试。

本地 `.txt`、`.csv`、`.tsv`、`.toml`、`.yaml` / `.yml`、`.jsonl`、`.log`、`.ini` 文件链接使用同一个预览窗口按纯文本显示，支持相对路径、绝对路径和本机 `file://` 链接，也可从 Markdown 文档中打开相对链接。保留换行、空格和 Tab 缩进，Markdown、HTML 与脚本均按原文显示；可选中文本或复制完整原文。默认自动换行，可关闭后横向滚动查看对齐数据。空文件显示提示；加载中可关闭，读取失败可重试。CSV/TSV 暂不提供表格视图，配置文件不做解析或语法校验。JSON 继续使用现有格式化预览。

纯文本通过 `GET /api/threads/:threadId/text?path=...` 读取，复用现有会话项目/服务器临时目录授权、符号链接检查与禁止缓存规则；仅支持不超过 2 MiB 的 UTF-8 普通文件，拒绝无效编码与含 NUL 的二进制内容。非 UTF-8 文件需先转换编码。

回复和 Markdown 文件预览中的 `mermaid` 代码块会显示为图表。流式输出尚未闭合代码块时显示等待提示和源码，闭合后再渲染；执行结束或中断后也会尝试渲染剩余源码。语法错误或加载失败只影响该图表，保留提示与源码。工具栏提供「查看源码 / 查看图表」「复制源码」和「实际大小 / 适应宽度」，大图可在图表区域内横向、纵向滚动，不撑宽页面。剪贴板不可用时自动展示可手动选择的源码。图表跟随系统浅色/深色偏好，源码复制与会话导出仍保留文本。渲染器在浏览器内按需加载，不调用远程图表服务；使用 Mermaid 严格模式，以隔离的 SVG 图片显示，不绑定图表链接或脚本回调。源码不能覆盖安全配置或注入主题 CSS；渲染限制为 50,000 个源码字符、500 条边，超过限制时保留源码。

关闭所有页面不取消任务。重新打开获取当前快照；保有对应会话内存投影时可按游标补发。界面连接状态与最后已知执行状态独立。网络提交失败后保留操作 ID，刷新先查询旧结果，避免自动重复执行。`acknowledged` 只表示上游接受操作，并非任务完成。

服务或 Codex 异常退出后，无法确认的操作为 `unknown`，包括已确认但尚无终态的执行占用。点击提示中的“核对提交”会展开状态诊断，先刷新会话历史，再查询提交回执，并显示核对进度与查询错误。受管会话的未知状态也会重新读取 Codex 历史；只有匹配轮次的历史明确结束，且本会话没有其他活动任务时，才会自动解除本会话的执行占用。若仍待核对，在操作卡片中核实旧运行已经结束、勾选确认后，点击“核对并解除旧占用”；完成后会刷新状态，保留原操作状态和未发送草稿。上游仍报告活动时不能用核对绕过，应正常中断。

若回执查询返回 `404 / OPERATION_NOT_FOUND`，表示当前服务没有对应操作记录，可能是原请求未到达或服务数据已更换；这不能证明任务未执行。手动核对的查询错误会直接显示在页面和状态诊断中。仅存在于浏览器的记录可在检查会话历史、会话列表和原执行环境并明确确认后，点击“清除此浏览器的待核对记录”；此操作不会停止任务、删除服务端记录或自动重发，未发送的草稿会保留。网络故障或其他查询错误不提供此清理入口。

## 数据迁移、测试与协议

```sh
pnpm db:generate                         # schema -> 新 SQL 迁移及完整元数据
pnpm db:migrate -- --config ./config.local.json
pnpm codex:generate -- --config ./config.local.json
pnpm exec playwright install chromium
pnpm test:e2e                            # 显式模拟子进程，浏览器闭环
pnpm test:live                           # 真实握手、认证及模型诊断
pnpm test:live -- --inference             # 临时项目真实任务，会使用 Codex 额度
node --import tsx scripts/live-browser-smoke.ts --inference  # 真实 Chromium + Codex；需先 build 和安装 Chromium
```

启动自动应用**已提交**迁移；不自动生成、不使用 `drizzle-kit push`。迁移失败阻止启动 Codex 和派发任务，不重建或删除数据库。修改 schema 后生成新迁移；已应用迁移不可改写。SQLite 仅保存本应用项目注册、操作、执行标记、会话关联和偏好表，不复制 Codex 会话库，也不逐 token 写库。备份前停止网关，完整备份 dataDir；Codex 自己的历史与凭据仍由其管理。

`pnpm test` 和 CI 不使用真实账户推理。测试进程遵循已生成协议；模拟界面明确标识。生产启动失败显示诊断，不切换假数据。安装和启动均不重新生成协议、不升级全局 CLI。

输出默认每 item 2 MiB，事件缓存 16 MiB，连接发送缓冲 4 MiB，可通过 `limits.itemBytes/eventBytes/wsBytes` 修改。截断有标记；慢连接关闭后重新获取快照。Codex stderr 仅保留有界内存尾部，不输出凭据或完整环境。外部进程管理器的 stdout 日志需单独轮转。

首版不包含通用文件上传、交互终端、文件编辑器、Git 操作面板、队列、多用户及自动管理 worktree。电脑休眠或停机时无法保证运行状态；不提供唤醒功能。
