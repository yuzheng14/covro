# 会话历史加载与缓存

打开会话时，支持分页的 Codex 历史只读取最近 12 轮，较早历史按同样大小分片。每轮的条目按 20 条读取，以保留大工具输出的 JSONL 传输边界。旧版 legacy 历史没有分页能力，沿用全量读取；导出始终读取完整已保存历史。

向上滚动进入距顶部约 1.5 个视口（至少 600px）的区域时开始预加载。每个会话最多一个历史读取请求；较早内容加载后保留，因此向下滚动或重复经过同一区域不产生重复请求。未到边界不继续扫描整段历史。插入分片以稳定轮次 ID 恢复首个可见轮次的偏移，流式更新保留当前阅读位置。到达末页停止；失败保留已加载内容并提供重试。切换会话取消历史读取，迟到结果也会检查所属会话。

## 实时同步

首次打开和无法继续重放时，通过 HTTP 读取完整的最近历史页及恢复游标；WebSocket 随后只传递消息变化、文本增量和控制状态。实时更新不会覆盖或缩短已加载的完整正文。加载期间的新事件按游标补齐；切换会话和断线会取消旧读取，重复事件不重复追加。单条替换数据超出连接预算时重新读取 HTTP 历史，不向正文插入传输截断提示。已有的单条输出保留上限仍由 itemBytes 控制。

## 本机缓存

IndexedDB 中每条记录对应一个历史分片。再次打开或刷新页面时只读取最近一片；滚动需要的较早分片再单独查缓存，同时与服务端核对。服务端按稳定轮次 ID 替换整轮内容，所以回复修改、轮次状态与新增消息都会得到校正。缓存不恢复 WebSocket 游标，也不参与任务执行、自动恢复或审批。显示缓存时会提示正在同步或同步失败，活动中的缓存状态降为“未知”，操作入口等待真实服务端数据。

缓存范围由经过认证的接口确认，包含当前服务端进程、Codex 实例、用户身份、项目 ID、根目录及可用性。用户身份只在服务端参与哈希，不保存 JWT 或明文用户标识。重启服务或 Codex、切换用户、改变项目上下文都会生成新命名空间。认证失败、会话删除或访问被拒绝时，不再显示该会话缓存并清理相应记录。完全离线的新页面无法重新确认身份，因此不会读取此前身份下的缓存；已确认身份的页面遇到临时网络故障时可以继续阅读缓存；历史请求失败后，可通过“继续读取本机历史”逐片读取更早的缓存，不再发起网络请求。重新同步会串行核对本次已打开的缓存分片。

会话历史与列表缓存共用 8 MiB 总量、256 条记录上限，单条最多 512 KiB，有效期 7 天。写入时按最早写入时间回收超额、过期或版本不兼容的记录；读取会拒绝过期或校验失败的记录。缓存摘要用于检测损坏。超过单片上限的内容仍正常从服务端读取。浏览器拒绝存储、清理数据、配额耗尽或缓存损坏均按未命中处理，不影响服务端分页。浏览器清理本网站数据可删除全部缓存。

## 会话列表缓存

会话摘要与历史分片复用同一个 IndexedDB 存储、摘要校验和认证缓存命名空间，不引入额外依赖。普通与归档列表单独保存，每个项目/筛选最多保存最近 300 条摘要；不保存分页游标、WebSocket 游标、待处理审批或运行状态。再次打开、刷新页面或切换筛选时，已确认身份的页面先显示对应缓存，并将状态显示为“待核对”。切换项目沿用已加载的独立项目列表，无需再读一遍服务端。

后台从当前首页开始核对新增、标题、排序、更新时间及归档状态。同一项目和筛选的并发同页读取会去重，切换筛选取消旧请求；迟到缓存不能覆盖服务端结果、实时事件或乐观操作。缓存只补充未被新状态替代的条目；持久化保存底层服务端摘要，不保存乐观改名或归档投影。身份上下文变化会移除尚未核对的缓存行；403/404 拒绝列表访问时清空可读缓存并删除该项目列表快照。

服务端返回一页时保留未见到的缓存尾部，并明确提示“部分本机列表尚未同步，加载更多以核对”。加载更多从这次服务端返回的游标继续；一页中命中尚未核对的缓存条目时停下，不为寻找新 ID 而扫描所有缓存页。仅在用户遍历到末页后，才删除整个遍历中始终缺席的条目并显示“已加载全部会话”；实时通知仍按版本更新或移出单条摘要。排序变化使用稳定会话 ID 合并，更新前记录可见行并恢复屏幕偏移，不改变当前选中会话。

网络失败保留本机列表并显示同步失败及重试入口；存储不可用、过期、结构损坏或摘要校验失败均降级为服务端加载。完全离线的新页面仍需先确认身份，不能跳过缓存身份校验。后台首页不会主动核对所有尾部缓存；这些条目保留“待核对”状态，直到对应分页或实时通知确认。因此重新打开的列表只请求首页，额外数据随用户加载更多读取。写入按项目合并短时通知，未变化的其他项目列表不重复写入；历史与列表统一按容量、记录数及期限清理旧记录。

验收文件：`tests/e2e/thread-list-cache.spec.ts`、`tests/e2e/thread-list-cache-storage.spec.ts` 和 `tests/web/project-threads.test.ts`。性能记录区分缓存可见时间与首页同步完成时间，并记录首页/加载更多请求、响应字节和可见行偏移。浏览器运行使用明确夹具与受控延迟，不发起真实模型请求。
